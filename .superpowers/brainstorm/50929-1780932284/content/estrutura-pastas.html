Como organizar as pastas e URLs?

Você quer organizar por tipo de trabalho. Três formas de fazer isso no mesmo projeto Vercel.

A

Adicionar como novo serviço do cliente (mais simples)

Mantém a estrutura atual. calendario-editorial entra junto com identidade-visual e logo.

Estrutura de pastas
clientes/
  quikciadadanca/
    moverconsciente/ ← identidade visual
    calendario-editorial/
      index.html
  studioalma/
    identidade-visual/
    calendario-editorial/

URL: lab360-entregas.vercel.app/clientes/studioalma/calendario-editorial/

Prós

  • Zero refatoração no existente
  • URL simples

Contras

  • Não separa visualmente os tipos de trabalho
B

Subpasta por categoria de serviço

Cada cliente tem duas grandes categorias: identidade-visual e gestao-de-redes-sociais. Dentro de cada uma, os serviços específicos.

Estrutura de pastas
clientes/
  studioalma/
    identidade-visual/
      index.html
    gestao-de-redes-sociais/
      calendario-editorial/
        index.html

URL: lab360-entregas.vercel.app/clientes/studioalma/gestao-de-redes-sociais/calendario-editorial/

Prós

  • Separa claramente as áreas de trabalho
  • Fácil adicionar futuros serviços (relatório, estratégia…)

Contras

  • URL mais longa
  • Pequena refatoração nos existentes
C

Mês como pasta independente

Cada entrega mensal vira uma pasta separada com o mês no nome. Histórico completo de entregas por cliente.

Estrutura de pastas
clientes/
  studioalma/
    identidade-visual/
    calendario-jun-2025/
      index.html
    calendario-jul-2025/
      index.html

URL: lab360-entregas.vercel.app/clientes/studioalma/calendario-jun-2025/

Prós

  • Histórico completo e acessível
  • URL curta e direta

Contras

  • Mistura tipos de trabalho diferentes no mesmo nível
  • Pode ficar bagunçado com muitos meses
